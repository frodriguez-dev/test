Explicación de los archivos del repositorio
===========================================

Este documento describe los archivos que tiene el repositorio actualmente.

calculator.py
    Módulo principal con la lógica de la calculadora. Define dos funciones:
      - add(a, b): devuelve la suma de a y b.
      - subtract(a, b): devuelve la resta de a menos b.

pyproject.toml
    Archivo de configuración del proyecto en formato PEP 621.
    - Define el proyecto "openhands-test" versión 0.1.0 y requiere Python >= 3.10.
    - Declara la dependencia de desarrollo "pytest>=8".
    - Configura pytest (pythonpath = ["."] y testpaths = ["tests"]).

README.md
    Archivo de texto breve con la descripción del proyecto: "OpenHands Test".

.gitignore
    Lista de archivos y directorios generados automáticamente que no deben
    versionarse (por ejemplo, __pycache__/, *.pyc y *.egg-info/).

tests/
    Directorio que contiene las pruebas automatizadas.

    tests/test_calculator.py
        Pruebas unitarias de las funciones de calculator.py:
          - test_add
          - test_subtract_two_positive_numbers
          - test_subtract_negative_result
          - test_subtract_negative_numbers
          - test_subtract_zero_result

Archivos generados automáticamente (ignorados por .gitignore)
--------------------------------------------------------------
Estos no se versionan en el repositorio:

    __pycache__/ y tests/__pycache__/
        Directorios creados por Python con los archivos compilados
        (por ejemplo, calculator.cpython-314.pyc).

    openhands_test.egg-info/
        Directorio de metadatos generado al instalar el paquete
        (PKG-INFO, SOURCES.txt, dependency_links.txt, top_level.txt).

.git/
    Directorio interno de Git con el historial y la configuración del
    repositorio.
